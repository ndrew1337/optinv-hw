Крипто-арбитраж
через Форда–Беллмана

Грицаев Андрей, Бугрышев Михаил

Основная идея

  • ◦Вершины – криптовалюты (BTC, ETH, SOL, USDT …).
  • ◦Рёбра – направленный обмен с курсом r и комиссией f.
  • ◦Цикл обменов, дающий больше валюты, чем вложили → прибыль.
w(u,v) = −ln(ruv·(1−fuv))
Πr > 1 ⇔ Σw < 0
Прибыльный цикл ⇔ отрицательный цикл → ищется Фордом–Беллманом.

Что такое L2 order book

Order book (стакан) – список активных заявок на покупку и продажу. Уровни детализации:

L1

Только лучшие bid / ask – одна строка с каждой стороны.

L2 · здесь

Несколько ценовых уровней вглубь + объёмы → глубина рынка.

L3

Каждый ордер по ID и очередь внутри уровня.

Зачем для арбитража: крупная заявка «съедает» уровни → реальная средняя цена хуже лучшей. Это проскальзывание, и посчитать его можно только по L2 – проходом по стакану.

Плюсы и минусы

＋ Плюсы

  • +Простота реализации, низкий порог входа (в т.ч. по железу).
  • +Возможность «относительно» честного бэктеста.
  • +Проверка на реальном L2-стакане, а не только на свечах.
  • +Честная модель: без look-ahead, с латентностью и инвентарём.

− Минусы

  • −Большая конкуренция; HFT-фонды забирают прибыль.
  • −Комиссии съедают edge – на ретейле прибыли нет.
  • −Чувствительность к задержке и проскальзыванию.
  • −Нужны короткие циклы; вывод/перевод между биржами медленный.
